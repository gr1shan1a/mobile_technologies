# mobile_technologies

## VocExtender 0.3.0

Учебное приложение для самостоятельного повторения английской лексики на ОС Аврора. Пользователь выбирает направление EN→RU или RU→EN, одну из шести тем, один из четырёх форматов самостоятельной практики и размер случайной подборки от 1 до 10 карточек.

Словарь содержит 60 карточек с переводами и примерами. Ответ можно открывать и скрывать повторно; сложную карточку можно вернуть в конец очереди. Результат показывает самооценку пользователя и не проверяет знание автоматически. Работа приложения не требует интернета; прогресс не сохраняется между занятиями.

### Сборка и проверка

Откройте `ru.student.VocExtender.pro` в Aurora IDE, выберите SDK BT, Docker-среду сборки, архитектуру aarch64 и эмулятор. Логику словаря и тренировочной очереди можно проверить командой `node tests/test-vocabulary.js`.

### Отчёты

Исходники отчётов Typst: `report-lab1.typ`, `report-lab2.typ`, `report-lab3.typ`. Скриншоты для отчётов находятся в `images/lab1/` и `images/lab2/`. PDF можно собрать, например, командой `typst compile report-lab3.typ report-lab3.pdf`.

Перед сдачей отчёта укажите фактическую дату отправки, добавьте электронную подпись на титульный лист и проверьте ссылку на репозиторий.
