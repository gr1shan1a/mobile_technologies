# VocExtender 0.3.0

Учебные карточки английской лексики для ОС Аврора.

Выбор направления EN→RU / RU→EN → одна из 6 тем → режим Listening / Grammar / Speaking / Writing → количество от 1 до 10 → случайная тренировка → результат.

База: 60 карточек, по 10 на тему. Первичная выборка без дубликатов. «Повторить позже» возвращает карточку в конец очереди. «Новая подборка» повторно перемешивает набор. Режимы используют общую базу и разные инструкции для самостоятельной работы: аудио, записи речи, редактора текста и автоматической проверки нет. Прогресс не сохраняется.

Открыть ru.student.VocExtender.pro в Aurora IDE, запустить Docker Desktop, выбрать aarch64 и эмулятор. Собрать и запустить. Интерфейс использует штатный шрифт Silica и Theme.

Итог тренировки включает долю карточек, отмеченных пользователем знакомыми. Это самооценка, она не проверяет знание автоматически.

Проверки логики: `node tests/test-vocabulary.js`. Node нужен только для теста, не для приложения.
