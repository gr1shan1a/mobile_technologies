# Как переработать отчёт ЛР1 из DOCX в Typst

DOCX можно использовать как источник текста, таблиц и изображений, но требование преподавателя означает, что итоговый отчёт следует набрать в Typst на основе его шаблона. Самый надёжный путь — открыть `report_example.typ`, сохранить рабочую копию рядом с иллюстрациями, заменить демонстрационный текст на материал ЛР1, а скриншоты извлечь из DOCX и подключить конструкцией `#image("images/filename.png", width: 80%)` с подписью рисунка. Изображения из Word удобнее извлечь через «Сохранить как веб-страницу» (получится папка с медиафайлами), либо открыть копию `.docx` как ZIP и взять файлы из `word/media`. Не вставляйте содержимое DOCX в Typst как код и не переименовывайте DOCX в `.typ`: форматирование Word автоматически в шаблон Typst не переносится.

Сохраните шаблон и отчёт в одной папке, например `report.typ` и `images/aurora-main.png`. В шаблоне сохраните параметры кафедры и титульную структуру, заполните свои ФИО, группу, дисциплину, преподавателя и название ЛР1. Подставьте дату отправки в ЛК и оставьте предусмотренное место для электронной подписи, если оно есть в шаблоне. В основной части оформите разделы «Задача», «Концепция», «Анализ аналогов», «Предварительный начальный макет», «Первая тестовая версия» и «Вывод». Перенесите текст из DOCX, затем замените изображения ссылками на извлечённые картинки и добавьте подписи. Для кода/команд используйте блоки raw, для сравнений — таблицы Typst.

Установите Typst с официального сайта или через пакетный менеджер. Из каталога отчёта выполните `typst compile report.typ report.pdf`. Исправьте сообщения компилятора до успешной сборки, откройте полученный PDF и проверьте переносы, нумерацию рисунков, читаемость снимков, актуальность титульника, дату, подпись и адрес GitLab. Электронную подпись добавьте в PDF подходящим редактором, затем сохраните подписанный итоговый файл и проверьте, что он открывается.
